## Status Legend

| Status | What It Means |
|--------|--------------|
| **Onboarding** | Client paid, onboarding form sent, waiting on their info |
| **Building** | Form received, actively configuring automations in GHL |
| **Review** | Build complete, sent to client for approval/feedback |
| **Live** | Client approved, automations are active and running |
| **Active** | Everything running smoothly, in normal monthly support mode |
| **Paused** | Client requested pause (seasonal, financial, etc.) |
| **Churned** | Client cancelled — document reason for future reference |

## Onboarding Checklist

Use this for every new client. Copy it into a note or new section per client.

### Pre-Setup
- [ ] Payment received and confirmed
- [ ] Welcome email sent with onboarding form link
- [ ] Onboarding form filled out by client
- [ ] Form data reviewed — all required fields complete
- [ ] Client added to this tracker (Status: **Onboarding**)

### Build Phase
- [ ] Status updated to **Building**
- [ ] GHL sub-account created for client
- [ ] Business info entered (name, phone, address, hours)
- [ ] Missed call text-back configured
- [ ] After-hours auto-response set up
- [ ] Appointment/booking follow-up sequence built
- [ ] Review request sequence built
- [ ] Message tone matches client preference (Professional / Friendly / Casual)
- [ ] Booking link added (if provided)
- [ ] Google Business Profile linked (if provided)

### Review Phase
- [ ] Status updated to **Review**
- [ ] Internal test run — all automations fire correctly
- [ ] Review call or loom video sent to client
- [ ] Client feedback received
- [ ] Revisions made (if any)
- [ ] Client gives final approval

### Go-Live
- [ ] Status updated to **Live**
- [ ] All automations activated
- [ ] Client notified: "You're live!"
- [ ] First check-in scheduled (1 week out)

### Ongoing (Active)
- [ ] Status updated to **Active**
- [ ] 30-day check-in completed
- [ ] Monthly billing confirmed recurring
- [ ] Any issues or change requests logged in Notes

## Notes Template (Per Client)

When adding a client row, use the Notes column for quick flags like:
- `Form rcvd 06/10` — date form was submitted
- `Uses Tekmetric` — CRM they're on
- `No Sat/Sun` — closed weekends
- `Wants casual tone` — message style
- `Check in 06/20` — follow-up reminder
- `Pause req'd — back 09/01` — if paused
