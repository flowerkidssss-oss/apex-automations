# Apex Automations — Outreach Scripts

## Strategy
Target: Auto detailers and body shops on Google Maps, Instagram, and Facebook.
Goal of first message: not to sell — to start a conversation and qualify.
Rule: one message at a time. No walls of text. No pitching in message 1.

---

## Channel 1 — Instagram DMs

### Message 1 (cold opener)
```
Hey [Name]! Found your shop on Instagram — the work looks clean 🔥

Quick question: when someone calls and you miss it, do you have anything set up to follow up automatically?
```

### If they say "no" or "not really":
```
That's actually super common. Most shops lose 20–30% of leads just from slow follow-up — people call 2-3 places and go with whoever responds first.

I run a service that handles all that automatically — instant text-back on missed calls, follow-up sequences, review requests — all set up for you. Takes about a week to install.

Worth a quick 15-min call to see if it'd be a fit for you?
```

### If they say "yes we have something":
```
Nice, good to hear. What are you using?

[Listen. If their system is weak/basic:]
Got it — there may still be some gaps worth plugging. Mind if I ask a couple quick questions?
```

### If they ghost after message 1:
```
[3 days later]
Hey — just circling back real quick. Not trying to spam you, just thought this could actually be useful given how lead-heavy the detail business can be. Happy to show you a quick demo if you're curious. No pressure either way 🤙
```

## Channel 2 — Google Maps Cold Call Script

**Pre-call prep:** Look up the shop name, owner name if available, check if they have Google reviews (low reviews = perfect prospect).

```
YOU: "Hey, is this [Shop Name]?"

THEM: "Yeah."

YOU: "Hey, my name's Roger, I run a company called Apex Automations. Quick question — when someone calls your shop and nobody picks up, what happens to that lead?"

[Let them answer]

THEM: "We call them back." / "Nothing, really." / "We try to..."

YOU: "Got it. So the reason I'm calling — we set up an automatic system that texts that person back within 60 seconds, and then follows up with them over the next week until they book. Shops we work with usually see a pretty immediate jump in booked jobs just from leads that were slipping through.

It takes about a week to get live and we handle the whole setup. Would it be worth 15 minutes to see how it would work for your shop specifically?"

[If yes: book a call]
[If not now: "No worries at all. Can I send you a quick overview so you have it for later?"]
```

## Channel 3 — Cold Email

**Subject line options:**
- "Quick question about [Shop Name]'s missed calls"
- "[Shop Name] — are you following up on every lead?"
- "How many leads is [Shop Name] losing per week?"

**Body:**
```
Hey [Name],

Found [Shop Name] on Google — the reviews look solid.

Quick question: when someone calls and nobody answers, do you have an automated follow-up in place, or does that lead just go cold?

The reason I ask — most auto detail and body shops lose 20–40% of inbound leads just from slow response time. People call a few shops; whoever texts back first usually gets the job.

I run a done-for-you automation service specifically for shops like yours. We install:
- Instant missed call text-back
- 7-day follow-up sequence for new leads
- Automated review requests after every job
- Reactivation messages to past customers

Setup takes about a week. No tech skills needed on your end.

Would a quick 15-minute call be worth your time?

— Roger
Apex Automations
[phone / calendar link]
```

## Objection Handling

**"We're too busy to set it up."**
"That's exactly why it makes sense — you're busy because leads are coming in. This runs without you. Setup takes one 30-min call from you, then we handle the rest."

**"We already have something."**
"What are you using? [listen] Got it — a lot of tools don't have the follow-up sequencing or the reactivation piece. Would it be worth seeing what gaps exist?"

**"How much does it cost?"**
"$1,500 to set up, $400 a month after. Most shops book 2–3 extra jobs in the first month just from the missed call flow — usually pays for itself."

**"I need to think about it."**
"Totally fair. What's the main thing you'd want to think through? I want to make sure I'm answering the right question for you."

**"We don't have the budget right now."**
"I hear you. What if I showed you a demo first — no commitment — so you can see exactly what it does? Then you can decide when the timing's right."
